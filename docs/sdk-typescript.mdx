El SDK oficial de TypeScript envuelve la **API v2** con tipos generados desde el
contrato OpenAPI, errores tipados y reintentos controlados. Cero dependencias de
runtime; funciona en Node.js 22+ (ESM y CommonJS).

## Instalación

```bash
npm install @cotizave/sdk
```

## Autenticación

La clave se envía como encabezado `X-API-Key`. Léela desde una variable de entorno
del servidor; nunca la incluyas en código de navegador.

```ts
import { Cotizave } from "@cotizave/sdk";

const client = new Cotizave({ apiKey: process.env.COTIZAVE_API_KEY! });
```

## Tasas por país

```ts
const { rates } = await client.rates.list("AR");
const trm = await client.rates.get("CO", "co-trm");
```

## Conversiones

```ts
const result = await client.convert({ from: "USD", to: "BRL", amount: 100 });
```

## Histórico

```ts
const point = await client.history.get({ country: "CO", rateId: "co-trm", date: "2026-10-01" });
const series = await client.history.daily({ country: "AR", rateId: "ar-official", from: "2026-09-01", to: "2026-09-30" });
```

## Manejo de errores

```ts
import { CotizaveError, CotizaveRateLimitError } from "@cotizave/sdk";

try {
  await client.rates.get("CO", "inexistente");
} catch (err) {
  if (err instanceof CotizaveRateLimitError && err.isQuotaExhausted) {
    // cuota mensual agotada
  } else if (err instanceof CotizaveError) {
    console.error(err.status, err.code, err.message);
  }
}
```

## Límites de uso

El SDK respeta la cuota mensual y el límite por minuto. En un `429`,
`CotizaveRateLimitError.scope` distingue `monthly` (cuota) de `burst` (velocidad).
Reintenta automáticamente los `GET` elegibles, nunca una cuota agotada.

## Seguridad de la API key

Uso exclusivo del lado del servidor. En Next.js, usa Route Handlers o Server
Actions. La clave viaja solo en `X-API-Key`, nunca en la URL.
