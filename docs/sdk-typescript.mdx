The official TypeScript SDK wraps the **API v2** with types generated from the
OpenAPI contract, typed errors and controlled retries. Zero runtime dependencies;
runs on Node.js 22+ (ESM and CommonJS).

## Installation

```bash
npm install @cotizave/sdk
```

## Authentication

The key is sent as the `X-API-Key` header. Read it from a server-side environment
variable; never ship it in browser code.

```ts
import { Cotizave } from "@cotizave/sdk";

const client = new Cotizave({ apiKey: process.env.COTIZAVE_API_KEY! });
```

## Rates by country

```ts
const { rates } = await client.rates.list("AR");
const trm = await client.rates.get("CO", "co-trm");
```

## Conversions

```ts
const result = await client.convert({ from: "USD", to: "BRL", amount: 100 });
```

## History

```ts
const point = await client.history.get({ country: "CO", rateId: "co-trm", date: "2026-10-01" });
const series = await client.history.daily({ country: "AR", rateId: "ar-official", from: "2026-09-01", to: "2026-09-30" });
```

## Error handling

```ts
import { CotizaveError, CotizaveRateLimitError } from "@cotizave/sdk";

try {
  await client.rates.get("CO", "does-not-exist");
} catch (err) {
  if (err instanceof CotizaveRateLimitError && err.isQuotaExhausted) {
    // monthly quota exhausted
  } else if (err instanceof CotizaveError) {
    console.error(err.status, err.code, err.message);
  }
}
```

## Rate limits

The SDK respects both the monthly quota and the per-minute limit. On a `429`,
`CotizaveRateLimitError.scope` tells `monthly` (quota) from `burst` (velocity).
Eligible `GET` requests are retried automatically; an exhausted quota never is.

## API key security

Server-side use only. In Next.js, call it from Route Handlers or Server Actions.
The key travels only in `X-API-Key`, never in the URL.
